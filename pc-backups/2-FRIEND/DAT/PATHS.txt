SWOOD DAT overlay — paths
=========================

<APP.USERPATH> = SWOOD Data Directory (the folder that CONTAINS DAT).
Typical:
  D:\SWOOD_LIBRARY 2026\DATA
  C:\Swood\Data Directory - v3.0

Copy folder 2-DAT (this tree) over:

  <APP.USERPATH>\DAT\

Reports (Report.cfg REPORTPATH):

  C:\Swood Reports\<YEAR>_<MONTH>\<SW.TITLE>

Files this overlay expects
--------------------------
  <APP.USERPATH>\DAT\Report.cfg
  <APP.USERPATH>\DAT\report\assets\settings\swood-client.js          (obfuscated in the friend pack)
  <APP.USERPATH>\DAT\report\assets\settings\view-settings.js
  <APP.USERPATH>\DAT\report\assets\settings\data-settings.js
  <APP.USERPATH>\DAT\apps\SheetMetalGeometry.vbs
  <APP.USERPATH>\DAT\apps\MACROS\SheetMetalGeometry.swp               (you copy the .swp here)
  <APP.USERPATH>\DAT\apps\NestingWorks.exe                            (from SWOOD / your build)
  <APP.USERPATH>\DAT\apps\ReportDataPost.exe                          (already in a stock SWOOD DAT)
  <APP.USERPATH>\DAT\apps\eDrawingExporter\eDrawingExporter.exe       (stock SWOOD)
  <APP.USERPATH>\DAT\public\assets\images\origin.png                  (stock SWOOD)
  C:\Windows\System32\cscript.exe

SOLIDWORKS property forms (optional):
  <SOLIDWORKS>\lang\english\sheetmetal.prtprp
  <SOLIDWORKS>\lang\english\miscellaneous.prtprp
  <SOLIDWORKS>\lang\english\glass-mirror.prtprp

Sheet-metal DXF job (keep ON)
-----------------------------
  [DXF_SHEETMETAL_PART]
    PATH            = <REPORTPATH>\dxfs\front-<NAME>_<CONF>.dxf
    AUTOPROCESS     = 1
    POSTPROCESS     = C:\Windows\System32\cscript.exe
    POSTPROCESSARGS = //nologo "<APP.USERPATH>\DAT\apps\SheetMetalGeometry.vbs" "<REPORTPATH>"

Real flats: dxfs\flat-*.dxf + db\sheetmetal-geometry.js
Do not nest Front views as flats.

Live report test (no Generate):
  also copy swood-client.js into <REPORTPATH>\assets\settings\ then Ctrl+F5
  DAT copy alone does not change an already-open report.
